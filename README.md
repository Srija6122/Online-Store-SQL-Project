# Online Store SQL Project

## Project Overview

This project is a Mini E-Commerce / Online Store database developed using MySQL.

The project manages customers, product categories, products, orders, and order items.

## Database

Database Name: `online_store`

## Tables

- Customers
- Categories
- Products
- Orders
- Order_Items
